# 跟单文件夹批量创建工具

本工具会在资源管理器右键菜单中添加“创建跟单文件夹”命令，用于批量创建跟单业务相关的子文件夹。

## 运行环境要求
- Windows 7/8/10/11（系统自带 .NET Framework 4.x，无需额外安装）
- 安装/卸载需要管理员权限
- 不依赖其他运行环境

## 文件说明
- FolderCreator.exe：主程序（C# 编译，基于 .NET Framework，不依赖外部 DLL）
- FolderCreator.cs：主程序源码
- setup.bat：安装脚本（添加右键菜单）
- remove.reg：卸载注册表（移除右键菜单）
- README.md：说明文档

## 安装步骤
1. 将所有文件放到一个固定目录（建议不要放在临时目录）。
2. 右键点击 `setup.bat`，选择“以管理员身份运行”。
3. 看到绿色的“安装成功”提示即完成安装。

## 使用方法
1. 在任意文件夹上点击鼠标右键。
2. 在右键菜单中选择“创建跟单文件夹”。
3. 程序会自动创建以下子文件夹：
- 1.PI
- 2.采购合同
- 3.码单
- 4.进仓申请
- 5.单证资料
- 6.装柜图片
- 7.客户发票
- 8.信保资料
- 9.开票通知

## 卸载方法
1. 双击 `remove.reg`。
2. 在注册表编辑器确认窗口中点击“是”。
3. 卸载完成后可删除本程序所在文件夹。

## 注意事项
- 安装时必须以管理员身份运行 `setup.bat`。
- 安装失败请确认以管理员身份运行。
- 程序不会修改或删除已存在的文件夹。
- 建议将程序放在固定位置，移动程序后需重新安装。
- 右键菜单不显示时请尝试重新安装。

## 常见问题
Q: 点击右键菜单没有反应怎么办？
A: 请重新运行 `setup.bat` 进行安装。

Q: 提示“找不到应用程序”怎么办？
A: 请确保没有移动 `FolderCreator.exe` 的位置，如果移动过请重新安装。

Q: 安装时提示需要管理员权限怎么办？
A: 右键点击 `setup.bat`，选择“以管理员身份运行”。
